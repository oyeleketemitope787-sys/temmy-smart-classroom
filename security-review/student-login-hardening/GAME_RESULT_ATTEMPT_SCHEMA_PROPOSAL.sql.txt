-- Required function contract; these routines are NOT included or enabled by
-- this schema-only draft:
--
-- A) public.begin_number_challenge_attempt(p_session_token uuid, p_questions jsonb)
--    * Executable by service_role only after explicit ACL review.
--    * Validate the session token, expected game ID, expiration, used_at,
--      active class and active student.
--    * Create exactly one attempt for the session. Generate 15 questions on
--      the trusted server; store all answer keys privately.
--    * Repeated start calls must resume the same attempt, not replace its key.
--    * Return current prompt/options/hint only; never return correct index.
--
-- B) public.record_number_challenge_answer(
--       p_session_token uuid, p_question_index smallint, p_choice_index smallint
--    )
--    * Executable by service_role only after explicit ACL review.
--    * Lock session and attempt rows FOR UPDATE.
--    * Validate expiration, unused session, approved game ID, active student
--      and class, expected next question and option bounds.
--    * Derive correctness from the stored correct_choice_index; never accept

--    * Make same-answer retries idempotent; reject changed duplicate answers.
