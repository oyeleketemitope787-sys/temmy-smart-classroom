-- Required function contract; these routines are NOT included or enabled by
-- this schema-only draft:
--
-- A) public.begin_game_attempt(p_session_token uuid)
--    * Executable by the intended backend role only after explicit ACL review.
--    * Validate the session token, approved game ID, expiration, used_at,
--      active class and active student.
--    * Read the game's question_count, max_score and score_rule_version from
--      the trusted central scoring catalogue.
--    * Generate the appropriate game-specific questions on the trusted server;
--      store answer keys privately and keep the generated version with attempt.
--    * Repeated start calls must resume the same attempt, not replace its key.
--    * Return current prompt/options/hint only; never return correct index.
--
-- B) public.record_game_attempt_answer(
--       p_session_token uuid, p_question_index smallint, p_choice_index smallint
--    )
--    * Executable by the intended backend role only after explicit ACL review.
--    * Lock session and attempt rows FOR UPDATE.
--    * Validate expiration, unused session, approved game ID, active student
--      and class, expected next question and option bounds.
--    * Derive correctness from the stored correct choice; never accept
--      is_correct, score, max_score, points_awarded, or game_name from browser.
--    * Make same-answer retries idempotent; reject changed duplicate answers.
--    * Record answer and update count/streak/verified score atomically.
--    * On final answer, store exact verified_score and game-specific max_score,
--      mark attempt completed, consume session, and create exactly one
--      point_transactions row with points = verified_score. Store the same
--      score/max in the central game-result record/response. All actions must
--      commit or roll back together; never clamp a valid score silently.
--    * A game allowing bonuses must configure max_score to include all bonuses.
--      For Number Challenge v1 that is 41 (15 base + 13 streak bonuses +
--      11 further streak bonuses + 2 final-question bonus). A game out of 20
--      with no bonuses has max_score 20 and a verified score of 16 awards 16.
--
--
-- C) Explicitly revoke default PUBLIC/anon/authenticated EXECUTE and grant only
--    the intended backend role on every new routine. Verify with
--    has_function_privilege() after creation.
